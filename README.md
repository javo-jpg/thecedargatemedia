# The Cedar Gate · media for scheduling

Public media for The Cedar Gate's social posts, used by Metricool to publish to Instagram, TikTok and LinkedIn.

- One folder per post: `<month>/<YYYY-MM-DD>-<post>/`
- Carousels: `01.jpg`, `02.jpg`… in slide order. Reels: `reel.mp4` + `cover.jpg`. `caption.txt` has every platform's caption. `linkedin.pdf` is the LinkedIn document version of a carousel.
- Stories: `<month>/stories/<YYYY-MM-DD>-<name>.jpg`
- Reels have no audio on purpose: music is added on the platform (classic country).

Raw URL pattern: `https://raw.githubusercontent.com/javo-jpg/thecedargatemedia/main/<path>`
